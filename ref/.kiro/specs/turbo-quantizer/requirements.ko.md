# turbo-quantizer — 요구사항

## 프로젝트 설명
고차원 임베딩을 3-bit 스칼라 양자화와 랜덤 직교 회전을 사용하여 압축하는 벡터 양자화 엔진. V1(단순 3-bit)과 V2(3-bit + 1-bit 잔차 보정) 알고리즘을 제공한다.

## 언어
ko

## 이해관계자
- 효율적인 임베딩 저장이 필요한 AI/ML 연구자
- 메모리 증강 AI 에이전트를 개발하는 엔지니어
- 대규모 역사 텍스트 말뭉치를 처리하는 팀

## 현재 상황
- **V1 (quantizer.py)**: 기본 3-bit 스칼라 양자화 + QR 분해 기반 랜덤 회전 행렬. 양자화 레벨은 균등 간격 가우시안 분위수, 잔차 보정 없음. 단순하지만 정확도 제한적.
- **V2 (memory.py)**: 랜덤 샘플 분위수 기반 데이터 중심 레벨을 사용한 개선된 3-bit 양자화, 벡터당 1-bit 잔차 인코딩(sign + scale), 재현성을 위한 고정 시드. 온라인 코드북 적응은 아직 없음.
- **코드 중복**: V1과 V2가 별도 파일에独立 구현, 공유 베이스 클래스나 전략 패턴 없음.

## 원하는 변경사항
