# ML 알고리즘 명세 (ml-spec.md)

### 수학적 인터페이스
- **입력**: 벡터 (vector)
- **출력**: 양자화된 결과 (quantized), 잔차 (residual)

### 정확도 측정 지표
- **vNMSE**: DRIVE/EDEN 기준 약 0.571 목표
- **Recall@K**: 검색 정확도 평가 지표

### 잔차 보정 요구사항
- **회전 공간 부호 저장**: 공유 회전 행렬 $R$을 사용하여 회전된 공간에서 부호(sign) 정보를 저장함
- **DRIVE 정리 2 적용**: 스케일 $s = E[|\langle r, y \rangle|] / d$ 공식을 사용하여 잔차 보정 수행

### 평가 데이터셋 기준
- vNMSE 및 Recall@K 성능 검증을 위한 표준 벤치마크 데이터셋 활용
